# DAFTAR — دفتر الأستاذ

DAFTAR تطبيق عربي لإدارة الدروس الخصوصية. يعمل دون حساب أو اتصال بالإنترنت، ويحفظ سجلاته على الجهاز. لا يرسل التطبيق بيانات التلاميذ أو المدفوعات إلى خادم.

## ما الذي يفعله؟

- إدارة الأفواج والجداول والتلاميذ، وتسجيل الحضور والدفعات والمصاريف.
- عرض ملخصات مالية شهرية وأرشفة السجلات واستعادتها.
- إنشاء نسخة احتياطية يدوية مشفّرة واستعادتها من ملف يختاره المستخدم.
- تذكيرات محلية للحصص، وخيارات المظهر الداكن والفاتح.
- قفل محلي برمز PIN من ستة أرقام، مع خيار البصمة أو التعرّف على الوجه على الأجهزة المدعومة.
- إعلان تحديث ثابت اختياري عند ضبط إصدار أحدث ورابط تنزيل HTTPS صالح؛ يفتح الرابط يدويًا ولا يثبّت التطبيق بصمت. لا توجد قناة تحديث مباشرة مهيّأة في هذا الإصدار.

لا تتوفر في هذه النسخة حسابات عبر الإنترنت، أو مزامنة سحابية، أو استعادة PIN عبر البريد أو الرسائل، أو دفع إلكتروني، أو لغات غير العربية. سجلات الدفعات والمصاريف محلية فقط.

## أين تُحفظ البيانات وكيف تُحمى؟

تُحفظ سجلات التطبيق الأساسية في مخزن التطبيق المحلي على هيئة حمولة واحدة مشفّرة بمصادقة **XChaCha20-Poly1305**. في نسختي Android وiOS يُنشأ مفتاح بيانات عشوائي بطول 256 بت، ويُحفظ عبر `expo-secure-store` كي تحميه آليات النظام (Android Keystore أو iOS Keychain). رمز PIN قفل للتطبيق، وليس مفتاح التشفير نفسه. تُرحّل البيانات القديمة المشفّرة بمفتاح مشتق من PIN إلى المفتاح المحمي عند أول فتح ناجح؛ وإذا تعذر فكها أو حفظ النسخة الجديدة، يبقى الملف القديم كما هو ولا يُستبدل ببيانات فارغة.

تُعطّل النسخة إعداد النسخ الاحتياطي التلقائي في Android لأن المفتاح مرتبط بالجهاز. استخدم التصدير اليدوي لنقل بياناتك بين الأجهزة. ملف التصدير مشفّر بصورة مستقلة باستخدام XChaCha20-Poly1305 ومفتاح مشتق من PIN مع PBKDF2-SHA256 (210,000 دورة) وملح عشوائي؛ احتفظ بالملف والرمز معًا في مكان آمن. قد تحتفظ بعض نسخ الجهاز الاحتياطية ببيانات مشفّرة من دون مفتاح الجهاز، لذلك لا تعتمد عليها بدل التصدير اليدوي.

على الويب، الذي يُستخدم للمعاينة فقط، لا يتوفر SecureStore/Keystore؛ لذلك يُشفّر التخزين المحلي بمفتاح مشتق من PIN داخل تخزين المتصفح. هذه الحماية أضعف من نسخة الهاتف، ولا يُنصح بإدخال سجلات حساسة في المعاينة.

التشفير لا يجعل أي برنامج غير قابل للاختراق. قد تنكشف البيانات إذا كان الهاتف مفتوحًا أو مخترقًا بصلاحيات الجذر، أو أصابه برنامج ضار، أو استُغلت ثغرة في النظام، أو قُرئت الذاكرة أثناء جلسة مفتوحة. رمز PIN قصير، لذا احمِ الهاتف نفسه، وأخفِ معاينات الإشعارات إذا كانت أسماء الأفواج حساسة، واحتفظ بنسخة يدوية مشفّرة ورمزها خارج الهاتف. نسيان PIN من دون نسخة احتياطية صالحة يعني عدم وجود مسار لاستعادة البيانات.

## التشغيل والفحوصات

يتطلب المشروع Node.js 22 وpnpm بالإصدار المحدد في `package.json`.

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm check
pnpm test
pnpm build
```

يبني `pnpm build` تصدير الويب الثابت في `dist/` ويضيف سياسة CSP محلية ووسوم العربية واتجاه RTL. لا يرفع الملفات ولا ينشر الموقع. الويب ليس بديلًا عن نسخة الهاتف عند حفظ بيانات فعلية.

لتشغيل نسخة Android محليًا بعد تثبيت Android SDK وتهيئة متغير `ANDROID_HOME` أو `ANDROID_SDK_ROOT`:

```bash
npx expo prebuild --platform android
npx expo run:android
```

لبناء APK محليًا بعد توليد مشروع Android:

```bash
cd android
./gradlew assembleRelease
```

لا يستخدم المشروع خدمة بناء سحابية، ولا ينشر APK أو ينشئ إصدارًا تلقائيًا. يفحص المشروع ترحيل البيانات والتشفير وفك التشفير والتلاعب بالملفات ونسخ البيانات الاحتياطية عبر Vitest.
